EEVsetup+ — комплект сайта

Внутри: index.html, style.css, script.js и инструкция. Установщики из чата не включены в ZIP из-за большого общего размера; положите их в папку installers рядом с файлами сайта.
Кнопки карточек расположены в порядке «На сайт» → «Инсталлер». Пароль для входа: 2323 (шуточный клиентский экран, не настоящая защита).

Важно для GitHub Pages: отдельные файлы больше 100 МБ нельзя загрузить обычным способом в GitHub. В этом комплекте есть установщики Discord, Epic Games, ShareX и HAPP больше 100 МБ. Для публикации вынесите эти крупные файлы на Google Drive/другое файловое хранилище и замените их href в index.html на прямые ссылки скачивания. Остальные файлы можно хранить в репозитории, если соблюдаются лимиты GitHub.

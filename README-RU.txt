EEVsetup+ — обновление на основе первого архива

Сохранены исходные значки и стиль существующих программ из присланного архива.
Карточки остаются кликабельными целиком — без кнопок «На сайт» и «Инсталлер».
Добавлены GearUP Booster и ExitLag в начало Network, Prism Launcher после Epic Games,
GTA5RP в конец Launchers, а Discord и Telegram вынесены в отдельную секцию ниже.
Для новых программ добавлены локальные SVG-эмблемы в зелёном стиле сайта.
Высота карточек и межсекционные отступы уменьшены умеренно.

Для GitHub Pages загрузите index.html, style.css, script.js и папку assets.
